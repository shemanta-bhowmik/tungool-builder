# Tungool Builder

A bundle of dynamic Gutenberg blocks for building pages.

## Development

```bash
composer install        # or: composer dump-autoload
npm install
npm run start           # watch blocks
npm run build           # build blocks → blocks/build/
npm run assets:build    # build admin/shared assets → assets/build/
```

See `CLAUDE.md` and `docs/` for architecture and block conventions.
